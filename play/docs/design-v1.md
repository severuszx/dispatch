# 《中国铁路调度》设计总纲 v1.0

## 〇、项目定位

类型：2D 轻量铁路调度游戏，以中国铁路为背景。

玩家角色：列车调度员/助调，不是司机，也不是站长。玩家面对 CTC 调度台、运行图终端、调度命令终端和电话。

核心乐趣：在有限股道、有限站台、有限时间、有限热备资源下做取舍；晚点不是随机弹窗，而是从人、设备、环境、管理四个维度涌现并传播。

双主线：

- 游戏线：调度学员成长、关卡、评级、图鉴、成就、剧情、每日挑战、回放"如果"分支。
- 拟真线：列调视角，CTC、非常站控、电话闭塞、命令校验、乘务超劳、车底接续全开，可复盘。

五模式：街机模式、标准模式、拟真模式、剧情模式、沙盘/自定义模式。

真实度滑块：自动进路、进路超时报警、命令校验、非常站控/电话闭塞、乘务超劳、车底接续、热备限制、天气设备健康度、晚点传播模型、复盘详细度。

## 一、核心循环与调度系统

核心循环：监视 CTC 站场图与运行图 → 发现偏离 → 判断影响范围 → 选择处置（调整运行计划/人工排列进路/发布调度命令/扣车/限速/封锁/启动热备/救援）→ 承担后果 → 复盘。

失败条件：正面冲突、追尾、脱轨立即失败；关键列车晚点超阈值、枢纽到发线全满、救援列车无法按时开出也可失败。

### 1.1 CTC 调度集中界面

站场图、区间闭塞分区、车次号追踪、运行图终端、报警栏。控制模式：分散自律控制模式 ↔ 非常站控模式。

### 1.2 进路与闭塞

进路类型：接车、发车、通过、调车。自动触发进路 45 秒超时报警。闭塞方式：自动站间闭塞、半自动闭塞、电话闭塞、移动闭塞。降级链：设备故障 → 基本闭塞法停用 → 发布调度命令 → 电话闭塞 → 通过能力断崖式下降。

### 1.3 调度命令系统

必须发布命令的情形：封锁/开通区间、救援列车、变更闭塞法、反方向行车、变更径路、临时降弓、临时限速、动车组空调失效开门限速、非到发线接发车、临时加开/停运。错发、漏发、受令者错误触发安全卡控。

### 1.4 列车优先级

G/D/Z/T/K/货/路用/救援/专运。影响待避顺序、热备启用优先级、晚点扣分权重。专运/军运可能只给密语。

## 二、晚点与特殊事件库

### 2.2 组合生成

晚点理由 = 根因（160+）× 位置（区间/站内/咽喉/分相/道岔/站台）× 阶段（始发/运行/终到/折返）× 处置分支（3—5）× 结果变体（3—5）× 传播层级（直接/一级/二级/三级）。160×4×4≈2560 条基础组合，乘位置阶段可到数千到上万条。

### 2.3 事件链示例

- 接触网断线 → 区间封锁 → 降弓通过限速 160 → 能力降至 40% → 热备不足 → 车底接续断裂 → 枢纽到发线满 → 站外停车 → 乘务超劳 → 邻局拒绝接入。
- 道岔失表 → 进站信号不能开放 → 列车已进入接近区段 → 必须先呼叫停车才能取消进路变更 → 改引导接车 → 站停延长。
- 春运 + 天窗超时 + 热备为零 → 临客密集 → 到发线满 → 一列故障即大面积晚点 → 取舍停运临客或全部接入。

## 三、基础设施与应急处置

车站：编组站、区段站、中间站、无人站、线路所；到发线、站台、道岔、联锁。

区间：双线/单线、闭塞方式、闭塞分区、允许速度、分相区、限速区段。

关键点：分相里程、列控等级切换点、ATO 切换点、异物侵限监测点、雨量计/风速计。

热备/救援：热备动车组、热备机车、热备车底；救援列车、供电抢修车、工务抢修车。

应急处置分支：接触网跳闸重合成功/失败/断线/覆冰；红光带、道岔失表、计轴故障、全站停电；自然灾害分级响应（>45mm/h 限 120，>60mm/h 限 45，积水高于轨面立即停车）；动车组轴温、ATP 故障、空调失效；异物侵限。

## 四、晚点传播与评分复盘

传播机制：区间能力下降、到发线占用、车底接续、乘务超劳、热备启用延迟。

评分维度：正点率（等级加权）、传播深度、命令合规性、应急时效、资源效率、安全底线。

复盘：运行图偏离热力图、关键决策打点、传播链、"如果"分支回放。

## 五、场景包与剧情

场景包：普速场、高速场、枢纽、单线、山区、沿海、高寒、分界口、口岸。

剧情章节：学员、春运、台风、地震、专运、事故调查、新线开通。多结局取决于正点率、安全底线、关键列车、热备/救援、命令合规、对话选择。

玩法钩子：检修线排队、镟轮排队、洗车排队、热备被占、等料、二级修超时、融冰除雪线不足。

### 9.4 机务折返段/机务段

### 9.5 与正线耦合

## 十四、面向非铁路迷的教程与术语教学层

### 14.1 原则

- 教程关和游戏模式必须解释术语；拟真模式可关闭解释。
- 每个教程关只引入 3—5 个新术语，不一次灌完。
- 术语首次出现：暂停 + 术语卡 + 白话解释 + 图示 + 一个"为什么重要"的例子。
- 术语卡可随时从图鉴/侧栏调出；支持"术语/白话"切换。
- 术语解释不改变专业逻辑，只降低理解门槛。

### 14.2 术语卡结构

术语名 / 英文或缩写 / 一句话白话 / 在游戏里影响什么 / 常见误解 / 图示。

示例：

- 红光带：轨道区段显示红色，表示"系统认为这里有车或轨道电路故障"。游戏里你要判断是真车还是故障，决定引导接车还是等电务。
- 道岔失去表示：道岔转不到位或信号收不到位置确认。游戏里进站信号可能开不了，列车可能要在站外停。
- 进路：列车从 A 点到 B 点要走的那条"锁定的路线"。排进路就是提前把道岔和信号设好。
- 闭塞：保证两列车之间有一段安全间隔的规则。电话闭塞是降级办法，通过能力会大幅下降。
- 非常站控：调度中心失去对车站的直接控制，车站值班员接管。你要打电话指挥，慢且容易出错。
- 降弓通过：列车把受电弓降下来，靠惯性滑过故障接触网区段。通常限速。
- 热备：备用动车组/机车/车底，故障时替换。用早了后面没牌。
- 调度命令：不是点一下就行，很多操作必须正式下命令给司机/车站，错发漏发会扣分甚至出险性事件。
- 到发线：车站里接发列车用的股道。满了列车只能在站外停。
- 咽喉：车站两端道岔密集区，进路会交叉，容易堵。
- 超偏载：货车装得超重或偏一边，必须倒装或调整。
- 超限货物：货物太宽太高，会车、过隧道、侧线通过都有限制。
- 危险品隔离：不同危险品不能随便放同一股道/同一列车/交会。
- 乘务超劳：司机/乘务员工作时间超限，必须换班，否则安全卡控。
- 车底接续：上一趟车的车底折返跑下一趟；晚到就传染下一趟。
- 天窗：留给施工维修的时间窗口。压缩天窗能多跑车，但设备更容易坏。

### 14.3 教程关序列与术语引入

教程 1：认识调度台。术语：CTC、站场图、车次号、股道、信号机、道岔、进路。目标：看懂一列车从进站到发车。

教程 2：两车会车。术语：闭塞、区间、待避、会让、到发线。目标：单线两站让两车安全交会。

教程 3：红光带与引导接车。术语：红光带、引导信号、进路锁闭、电务。目标：判断真占用还是故障，选择等待或引导。

教程 4：道岔失表与接近区段。术语：道岔失去表示、接近区段、取消进路、引导接车。目标：列车已接近时先呼叫停车再变更。

教程 5：调度命令入门。术语：调度命令、受令者、封锁区间、临时限速。目标：发对一条命令。

教程 6：晚点与传播。术语：始发晚点、运行晚点、传播晚点、正点率、热备。目标：用一次热备切断传播链。

教程 7：股道开放。术语：到发线、有效长、站台、咽喉、股道占用甘特图。目标：开局开放合适股道，避免站外停车。

教程 8：客运参与。术语：上水、吸污、卧具、票额、超员、旅客情绪值。目标：压缩停站与保服务的取舍。

教程 9：货运参与。术语：装车、卸车、排空、货检、超偏载、危险品隔离。目标：处理一次超偏载甩车。

教程 10：车辆段入门。术语：动车所、检修线、存车线、热备、车底接续。目标：排一次出所计划。

教程 11：沙盒开关。术语：功能开关、依赖关系、评分系数。目标：开一组开关并理解为什么难。

### 14.4 教程反馈

每次术语卡出现后，用一个小高亮指向界面元素；教程关结束给"术语掌握"清单；图鉴里可复习；错误操作时用白话提示"你刚才取消进路时列车已接近，应该先呼叫停车"。

## 十六、设计红线（修订版）

1. 不直接驾驶列车，所有操作通过进路、命令、运行计划间接实现。
2. 信息呈现优先：3 秒内看出哪条进路没排通、哪个区段红光带、哪列车站外停车、下一个传播受害者。
3. 拟真模式保留术语；教程/游戏模式必须解释术语。不再要求所有玩家硬啃术语。
4. 每个事件族至少两种代价结构不同的处置路径：快但风险高 vs 慢但安全；保 G vs 保货；封锁抢修 vs 降弓通过；启用热备 vs 等修复。
5. 信息不完整是玩法：司机只说"有异响"，你要不要扣车。
6. 晚点理由图鉴是长期内容：玩家收集"我遇到过接触线断线""我处理过计轴故障"。
7. 沙盒开关不是难度滑块，是可配置规则表；依赖缺失要提示。
8. 车辆段不是背景板，是车底接续和晚点的源头之一。
9. 股道不是被动资源，是可开放/封锁/预留/借道的卡牌化资源。
10. 教程关每关只教少量术语，术语卡可复习，错误提示用白话。
